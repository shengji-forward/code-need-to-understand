# Code Need to Understand

A progressive JavaScript/TypeScript learning repository organized into three complementary collections.

## Overview

This repository is structured as three interconnected collections:

```
code-need-to-understand/
├── practice/            # Hands-on learning roadmap (Modules 00-10)
├── knowledge/           # Programming fundamentals courses
└── learning-summary/    # Progress documentation & conceptual hierarchies
```

## Collections

### practice/ - Learning Roadmap

Hands-on practice collection with progressive modules (00-10) taking you from JavaScript fundamentals to production-ready TypeScript.

**What's inside:**
- Practice files with LEVEL 1/2/3 progression
- Exercise files with `TODO` tasks and matching solutions
- Interview questions with hidden answers
- Best practices and OpenCoach code references

**Start here:** `practice/README.md`

### knowledge/ - Programming Fundamentals

Theory courses covering computer science fundamentals and programming principles.

**What's inside:**
- CS61A SICP JavaScript Edition
- Source Academy course materials
- Foundational programming concepts

**Start here:** `knowledge/README.md`

### learning-summary/ - Progress Documentation

Conceptual hierarchies and learning progress tracking.

**What's inside:**
- Module learning summaries
- JavaScript/TypeScript hierarchy diagrams
- Architecture documentation

**Start here:** `learning-summary/README.md`

## Learning Philosophy

**Practice-First Approach**

1. **Practice/** - Primary learning path through hands-on exercises
2. **Knowledge/** - Supplementary theory to deepen understanding
3. **Learning-summary/** - Document progress and connect concepts

Do the practice first. Reference knowledge when stuck. Document insights in summaries.

## Quick Start

1. **Install dependencies:**
```bash
cd practice
npm install
```

2. **Run your first practice file:**
```bash
npx tsx 00-fundamentals/practice/01-variables-and-types.ts
```

3. **Complete an exercise:**
```bash
npx tsx 00-fundamentals/exercises/exercise-01-basic-syntax.ts
```

See `practice/QUICKSTART.md` for complete getting started guide.

## Navigation

- **New to programming?** Start with `practice/README.md` → Module 00
- **Want theory first?** Check `knowledge/README.md` → CS61A SICP
- **Tracking progress?** Review `learning-summary/README.md` → Your summaries
