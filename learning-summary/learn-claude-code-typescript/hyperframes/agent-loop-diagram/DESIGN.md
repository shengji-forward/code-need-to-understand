# Vercel Swiss Pulse

## Style Prompt

A precise, minimal technical explainer in the spirit of Next.js and Vercel launch visuals: black canvas, thin white diagram strokes, quiet grid structure, and one electric blue accent used only to show active loop state. The composition should feel like a polished architecture diagram, not a marketing hero or dashboard.

## Colors

- Background: `#050505`
- Surface: `#0A0A0A`
- Primary text and strokes: `#F5F5F5`
- Muted text and grid: `#737373`
- Hairline borders: `#262626`
- Active accent: `#0070F3`

## Typography

- Use `Geist`, `Inter`, `Helvetica Neue`, and system sans fallbacks.
- Use `JetBrains Mono` for code and role labels.
- Large labels use 700 weight; diagram and code labels use 500-600 weight.
- Keep letter spacing at `0`.

## Motion

- Subtle step reveal only: opacity, short y-offsets, line drawing, and restrained accent highlighting.
- Use `power3.out` or `power2.out`; no bouncy or elastic motion.
- Final active loop may pulse once or twice, but nothing should run forever.

## What NOT to Do

- No gradients, glowing blobs, neon clutter, glass cards, or decorative illustrations.
- Do not use multiple accent colors.
- Do not add stock imagery or unrelated UI chrome.
- Do not make the diagram feel sketchy, handwritten, or playful.
