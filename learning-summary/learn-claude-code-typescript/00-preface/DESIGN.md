## Style Prompt

Session 00 should feel like a pragmatic developer keynote, not a classroom slideshow. Use a dark neutral canvas, one electric blue accent, generous spacing, and crisp type hierarchy. The tone is Vercel-minimal with Matt Pocock-style code confidence: direct, calm, technical, and a little sharp. Every slide should make one point cleanly. If code appears, it should look intentional and reusable, not decorative.

## Colors

- Background: `#0B0F14`
- Surface: `#121923`
- Surface Alt: `#18212D`
- Text: `#F3F6FB`
- Muted: `#8A95A5`
- Accent: `#4EA1FF`
- Accent Soft: `rgba(78, 161, 255, 0.16)`
- Border: `rgba(255, 255, 255, 0.09)`

## Typography

- Display / UI: `Geist`, `Inter`, `Segoe UI`, sans-serif
- Code: `IBM Plex Mono`, `SFMono-Regular`, `Menlo`, monospace
- Headlines are compact and confident, with minimal ornament.
- Body copy should stay short and scan cleanly on screen.

## Motion

- Default motion: restrained fades, slide-ups, line reveals.
- Use fast, clean timing: roughly `220ms` to `420ms`.
- Motion should clarify sequencing, not create spectacle.
- Hard cuts and simple fades are preferred over theatrical transitions.

## Slide Principles

- One core idea per slide.
- Use full code or ASCII blocks only when the viewer may want to reuse them.
- Prefer cards, checklists, quotes, and timeline layouts over dense bullets.
- Keep code literacy high: show the real loop, the real harness formula, and the real learning path.

## What Not To Do

- Do not use purple gradients, neon glow, or futuristic AI visuals.
- Do not fill slides with long prose paragraphs or repeated card grids.
- Do not use more than one accent hue in the deck.
- Do not treat code as wallpaper; every code block must earn its space.
